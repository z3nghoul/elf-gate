# Ручные проверки

То, что нельзя автоматизировать без внешнего окружения. Отмечать `[x]` после проверки.

## Этап 3. Управление ядром

- [ ] Реальный сервер (VPS): подключиться к нему из TUI, затем
  `curl -x socks5h://127.0.0.1:10808 https://ifconfig.me` показывает IP сервера.
- [ ] Закрыть окно терминала крестиком или убить терминал: `pgrep -x xray` пусто.
- [ ] Смена сервера при активном подключении: ядро перезапускается с новым конфигом, старого процесса нет.
- [ ] `d` во время подключения (до готовности ядра) не оставляет процесс xray.
- [ ] Занятый порт (`nc -l 10808`) даёт сообщение «порт 10808 (socks) уже занят…», процесс не запускается.
- [ ] Неверный `xray_path` даёт сообщение про `xray_path`.

Автоматически уже проверено (Linux): `kill -9` приложения убивает дочерний `xray`
(`PR_SET_PDEATHSIG`), проход трафика по цепочке клиент -> локальный сервер -> HTTP,
остановка ядра, раннее падение ядра, занятый порт.
