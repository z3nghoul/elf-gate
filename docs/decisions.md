## Этап 6

### Кеш `xray run -test` (6.1)
- Ключ кеша: FNV-1a (64 бит) от JSON сгенерированного конфига (ключи объектов `serde_json` отсортированы, поэтому
  хеш стабилен). Криптостойкость не нужна: вход создаём мы сами, атакующего у кеша нет. Отвергнуто: крейт `sha2`
  (лишняя зависимость ради ключа кеша), `DefaultHasher` (не гарантирует стабильность между версиями Rust).
- Версия Xray = первая строка `xray version`; при смене версии кеш сбрасывается целиком.
- Файл `check-cache.json` лежит в каталоге состояния (не в `state.json`): `state.json` читают и пишут пути аварийной
  очистки, смешивать с большим кешем незачем. В кеш попадают только вердикты Xray (принят / отвергнут с причиной);
  «не удалось запустить» не кешируется.
- Параллелизм: общий `Semaphore(4)` в `Checker`; проверка перед подключением идёт через тот же `Checker`.
- «Перепроверка только изменившихся серверов» получается сама: после обновления подписки у неизменных серверов
  тот же конфиг, значит тот же ключ.
