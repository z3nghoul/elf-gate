# Windows: ручная проверка

Пункты, которые нельзя проверить на Linux. Отмечать `[x]` после проверки на Windows 10/11 x64.

## Этап 1. Каркас TUI

- [ ] `elf-gate.exe` запускается в Windows Terminal и в классической консоли (conhost), TUI рисуется без артефактов.
- [ ] Кириллица и символы `●`, `▶`, `▼` отображаются корректно.
- [ ] Каждое нажатие клавиши обрабатывается один раз (на Windows crossterm присылает события Press и Release, Release отфильтрован).
- [ ] Изменение размера окна не ломает раскладку; при размере меньше 80x24 появляется сообщение.
- [ ] Debug-сборка: `F12` вызывает панику, консоль возвращается в нормальный режим (курсор виден, эхо включено).
- [ ] Лог пишется в файл (`%APPDATA%\elf-gate\logs`) и ротируется по дням.

## Этап 2. Модель, парсер, конфиг

- [ ] `config.toml` создаётся в `%APPDATA%\elf-gate\` после добавления сервера через `a`.
- [ ] Ссылка с кириллицей и эмодзи вставляется из буфера обмена консоли (Ctrl+V / правый клик) и имя отображается корректно.
- [ ] После перезапуска добавленные сервера на месте.

## Этап 3. Управление ядром

- [ ] Запуск ядра не открывает окно консоли (`CREATE_NO_WINDOW`).
- [ ] После закрытия окна терминала крестиком в диспетчере задач нет `xray.exe` (Job Object, `KILL_ON_JOB_CLOSE`).
- [ ] Убийство `elf-gate.exe` в диспетчере задач убивает `xray.exe`.
- [ ] `d` и смена сервера останавливают `xray.exe` (на Windows остановка без grace-периода, `TerminateProcess`).
- [ ] `cargo test xray::integration_tests` проходит с `bin\xray.exe` (путь через `XRAY_PATH`).
- [ ] Реальный сервер: `curl.exe -x socks5h://127.0.0.1:10808 https://ifconfig.me` показывает IP сервера.
