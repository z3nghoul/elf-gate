Заметки здесь на случай, если она появится.

## `freedom` и приватные адреса (Xray 26.x)

`freedom`-аутбаунд, который получает трафик от VLESS-инбаунда, по умолчанию блокирует
цели в loopback и приватных диапазонах (в логе `target blocked by a finalrule`). Это
защита от SSRF: клиент не должен через сервер ходить в локальную сеть VPS.

**На реальном сервере это умолчание не трогаем.** Настройка
`"finalRules": [{ "action": "allow" }]` для `freedom` встречается только в тестовом
локальном сервере интеграционных тестов (`src/xray/integration_tests.rs`), потому что
там цель, HTTP-сервер теста, намеренно живёт на `127.0.0.1`. Нельзя переносить её в
конфиги, которые попадают на VPS.

Клиентский конфиг, который генерирует elf-gate, `finalRules` не использует. Поведение
клиентского `direct` для TUN-инбаунда нужно перепроверить на этапе 5.
